# Jira Mini - BA & QC Suite

Lightweight, modern Jira-style Scrum & Kanban board tailored for Business Analysts (BA) and Quality Control (QC) engineers.

Live GitHub Pages URL: [https://ardvarez.github.io/jira-mini/](https://ardvarez.github.io/jira-mini/)

## 🚀 Key Features

* **Authentication Guard:** Jira-style login screen restricting access to authorized user.
* **Scrum & Planning:** Active Sprint management, Backlog, and Full Kanban.
* **Epics Container:** Group stories, tasks, test cases, and bugs under project Epics with completion progress.
* **BA & QC Swimlanes:** Group by Epic, Role (BA / QC / Dev), or Priority.
* **Multi-Project Switcher:** Switch between Core Platform, Payment Gateway, and Mobile Apps.
* **Cloud Sync (GitHub Gist):** Sync data across devices using a private GitHub Gist with 1-click push and pull.
* **Zero Dependencies:** Runs directly on GitHub Pages or locally with built-in Node HTTP server.

## 💻 Local Development

```bash
# Start local server (auto opens browser on port 3000)
node server.js

# Or on Windows, double-click run.bat
```
